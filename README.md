## 📌 About The Project

**SimpleShop** is a frontend e-commerce web application developed using React.js. It provides a user-friendly shopping interface with dynamically fetched product images using API integration.

This project helped me gain practical experience in frontend development, API integration, and building interactive web applications.

## 🚀 Live Demo

🔗 **[Explore SimpleShop](https://simple-shop-rajesh.netlify.app/)**

## 🛠️ Technologies Used

- ⚛️ React.js
- 🟨 JavaScript
- 🌐 HTML5
- 🎨 CSS3
- 🔗 REST API Integration

## ✨ Key Features

- 📦 Dynamic product images fetched automatically through APIs.
- 🔄 API integration for retrieving product-related data.
- 🖥️ Interactive and user-friendly interface.
- 🧩 Reusable React components.
- 📱 Responsive frontend design.

## 🎯 Project Objective

The main objective of this project is to strengthen my frontend development skills and understand how APIs can be integrated to display dynamic content in a web application.

## 📚 What I Learned

- Building user interfaces using React.js.
- Fetching dynamic data using APIs.
- Working with React components.
- Improving frontend design and user experience.
- Deploying applications using Netlify.
